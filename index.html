This is the live version: job listings load fresh from Arbeitnow's public job API every time this page opens — real postings, real apply links, no snapshot. The API doesn't include German-level, sector, or seniority fields, so Experience level and Sectors are inferred from job titles/tags (best effort). Distance uses your browser's location plus OpenStreetMap geocoding of each job's city, so first use can take a few seconds and requires location permission.
